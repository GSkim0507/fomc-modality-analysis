1. 연구질문과 가설

RQ. FOMC 커뮤니케이션의 조동사(구문)는 경제 상황을 설명하는가?

가설 내용 검정 위치
H1 편집 가설 성명서의 조동사 분포 변화는 정책 사건에 따른 정형문의 삽입·삭제(계단)로 설명된다 L3 변화점·L5 정형성·E7 사건 연구
H2 층위 분업 가설 층위(장르 × 귀속)마다 조동사·구문 프로파일이 유의하게 다르다 L2 키니스·χ²·L7 다항로짓
H3 반경기 가설 (Kawamura) 조동사 밀도는 실물 활동(CFNAI)과 음의 관계 E3 회귀·E9 재현
H4 불확실성 가설 조동사(구문) 밀도는 불확실성(VIX)과 양의 관계이며, 편집되지 않은 층에서만 성립 E3·E4·E5 확정 ledger
H5 선행성 가설 텍스트 지표가 거시 변수를 선행한다 E6 CCF·Granger·예측 회귀

2. 코퍼스 조합 (전수)

성명서 {포함, 제외} × 의사록 {없음, 위원회 층만(C), 실질 층 전부(S)} × 기자회견 {없음, 의장 발화만} × 연설 {포함, 제외} = 24 − 공집합 1 = 23개, 여기에 비교용 미정제 전체(v2 방식, 기자·규정문·인용 성명서 포함) 1개 = 24개 코퍼스 정의. 이전 라벨 S1–S6은 별칭으로 유지(S1 = 성명서만, S2 = 성명서+위원회 층, S3 = 성명서+의사록 실질 층, S4 = 4장르 정제, S5 = 의사록만, S6 = 미정제).

분석 단위 3종: U1 조동사, U2 구문(modal + predicate), U3 조동사 + 동사 의미 부류. → 72회 실행.

기간·정규화는 각 표 안의 열: T1 2014–2026, T2 2020 제외, T3 2010–2026, H1 2014–2019, H2 2021–2026; N1 밀도(per 1k, pmw 병기), N2 점유율, N3 문서당 수.

3. 실험군 L — 코퍼스 언어학

블록 내용 통계
L1 코퍼스 기술 층위별 문서·토큰·조동사 수, pmw와 95% CI, 연도별 pmw, 문서 간 분산(Gries DP) Poisson CI, DP
L2 키니스·층위 분업 층위 vs 나머지의 조동사·구문 키니스; 층위 × 조동사 χ², Cramér's V, 표준화 잔차 log-likelihood G², log ratio, %DIFF, χ²
L3 통시 층위·조동사별 연도 pmw; 회의 단위 추세(Mann–Kendall τ, Sen 기울기); 성명서 변화점(PELT, 점유율·밀도)과 원인 문장; 계단 그림 MK, PELT
L4 연어·구문 조동사별 서술어 프로파일; distinctive collexeme(Fisher exact, G²); 조동사 간 JSD; 의미 부류 분포; KWIC 용례 Fisher, G², JSD
L5 정형성(성명서) 정형 문장 비율(연도), 구문 코호트 Kaplan–Meier 생존, 보유율 반감기, 편집 이벤트와 책임 문장 KM, 보유율
L6 문법 맥락·의미 유형 부정·수동·완료·진행·조건·인용·의문·축약·주어 유형·의미 유형(epistemic/deontic/dynamic 휴리스틱) 비율, 조동사 × 자질 χ² χ²
L7 다항로짓 조동사 선택 ~ 층위 + 시기 + 주어 유형 + 조건 + 인용 (기준 will), 유사 R² MNLogit
L8 be appropriate will/would/may/could + be appropriate: 층위 × 연도, 용례 —
L9 대조 의장(Yellen/Powell) 대조, 정책 국면 대조 χ²

5. 확정 규칙 (D15 계승)

Spearman T1·T2 모두 p < .05·동부호, H1·H2 반기 동부호, 토큰 ≥ 40, 제로 회의 ≤ 60% → 확정. T1에서만 유의 → 2020 의존. T1·T2 유의하나 반기 부호 불일치 → 시대 구성.
