# FOMC Modal-Verb Linguistics → Academic Paper

FOMC 코퍼스(2010–2026)를 이용한 조동사(modal verb) 언어학 실험과 학술논문화 프로젝트.

- `TASKS.md` — 작업 목록/상태
- `HANDOVER.md` — 인수인계서(진행 로그·결정 사항·환경)
- `docs/` — 단계별 분석 문서 (기존 보고서 분석, 세미나 초점, 선행연구, 논문 전략, 문헌 목록, 종합)
- `experiments/` — 실험 스크립트 (`.venv/bin/python experiments/XX.py`)
- `results/` — 표(`tables/`)·그림(`figures/`)
- `literature/` — 수집한 선행연구(OA) 및 노트
- `paper/` — 논문 초안
- `FOMC_corpus/` — 원 코퍼스 + 기존(1차) 분석

## Setup
```bash
/usr/bin/python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```
